# ACK Christ the King Ruai Website

A responsive informational website for **Anglican Church of Kenya (ACK), Christ the King Parish, Ruai**, created to share the church's history, identity, and contact information with the community.

## About the Project

The ACK Christ the King Ruai website is designed to provide visitors with an accessible and user-friendly way to learn about the parish, explore its history, and find contact information.

The website features a clean layout, responsive design, and a simple navigation system that works across desktop computers, laptops, tablets, and mobile devices.

## Features

- **Home Page:** Introduces ACK Christ the King Ruai and presents the church's identity.
- **Church History:** Shares the background and development of the parish.
- **Responsive Design:** Adapts to different screen sizes and devices.
- **Navigation Menu:** Provides easy access to the Home, History, and Contact sections.
- **Mobile Navigation:** Includes a hamburger menu for smaller screens.
- **Dark Mode:** Allows visitors to switch between light and dark themes.
- **Church Images and Logo:** Displays church branding and relevant imagery.
- **Contact Information:** Provides convenient access to contact details through clickable email and telephone links.
- **Event Section:** Highlights church events and community activities.

## Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, animations, and responsive design.
- **JavaScript** — Interactive features, including the mobile navigation menu and theme toggle.

## Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your actual GitHub username and repository name.

### 2. Open the Project

Open the downloaded project folder in Visual Studio Code.

### 3. Run the Website

Open `index.html` in your browser.

For a convenient local development experience, you can use the **Live Server** extension in VS Code.

## Website Deployment

The website can be deployed using GitHub Pages, allowing visitors to access it through a public URL.

To enable GitHub Pages:

1. Open the repository on GitHub.
2. Navigate to **Settings**.
3. Select **Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.

After deployment, GitHub will provide a link to the live website.
